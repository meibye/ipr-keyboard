# ipr-keyboard Services

Service reference aligned to repository implementation (audited 2026-10-04
against `systemctl list-unit-files` on the production Zero 2 W).

## Primary Services

| Service | Unit Source | Installed By | Purpose |
|---|---|---|---|
| `ipr_keyboard.service` | generated by `scripts/service/svc_install_systemd.sh` | `scripts/service/svc_install_systemd.sh` | Runs `python -m ipr_keyboard.main` as app user: the pen loop, the dashboard, the LED/menu and the panel |
| `bt_hid_agent_unified.service` | `scripts/service/svc/bt_hid_agent_unified.service` | `scripts/service/svc_install_bt_gatt_hid.sh` | BlueZ Agent1 pairing/authorization service |
| `bt_hid_ble.service` | `scripts/service/svc/bt_hid_ble.service` | `scripts/service/svc_install_bt_gatt_hid.sh` | BLE HID over GATT daemon: owns the GATT database, types the characters, publishes typing progress and the bond state |
| `ipr-provision.service` | `scripts/headless/ipr-provision.service` | `provision/04_enable_services.sh` | Permanent management hotspot on wlan0 (always-on; no cable required) |
| `irispen-mount.service` | `scripts/headless/irispen-mount.service` | `scripts/headless/install_irispen_mount.sh` | Mounts the IrisPen over MTP at `/mnt/irispen`. See `docs/operations/irispen-automount.md` |
| `ipr-firewall.service` | `scripts/headless/ipr-firewall.service` | `scripts/headless/install_firewall.sh` | Applies the nftables exposure for the current mode (production closes SSH and the dashboard) |

## Supporting units

| Service | Purpose |
|---|---|
| `ipr-led-boot.service` | Lights the status LED within seconds of power-on, long before the application |
| `ipr-oled-boot.service` | Shows boot progress on the panel until `ipr_keyboard.service` claims it. See `docs/hardware/oled-display.md` |
| `ipr-led-halt.service` | Turns the LED off only when it is safe to unplug |
| `ipr-cert-renew.service` + `.timer` | Renews the dashboard's TLS certificate |
| `ipr-failure@.service` | `OnFailure=` target that records a failed unit where it can be read days later. See `docs/operations/unsupervised-operation.md` |

Units named in earlier revisions of this file — `bt_hid_daemon.service`,
`bt_hid_uinput.service` and `ipr_backend_manager.service` — no longer exist.
The BLE HOGP daemon replaced the uinput-based stack.

## Install Sequence Used by Provisioning

`provision/04_enable_services.sh` executes:

1. `scripts/service/svc_install_bt_gatt_hid.sh`
2. `scripts/ble/ble_install_helper.sh`
3. `scripts/service/svc_install_systemd.sh`
4. `scripts/ble/ble_setup_extras.sh`
5. `scripts/service/svc_enable_services.sh`
6. installs `ipr-provision.service`
